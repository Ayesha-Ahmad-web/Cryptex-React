# Cryptex — React + Tailwind

A React + Tailwind CSS rebuild of the original static Cryptex landing page, with a
new "molten ember" color theme (gold → coral → violet gradient on a near-black
background) replacing the original green/cyan/purple palette. All original
sections, copy, and interactive behavior (mobile nav toggle, scroll-reveal,
tab switching, favorite-star toggle) are preserved.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```
